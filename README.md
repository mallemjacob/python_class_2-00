# Python Class Notes

This repo is organized by lesson topic. The archive and practice folders are
kept separate:

- `old_class/`: older class files, not changed during cleanup
- `coding_bat/`: CodingBat practice files, not changed during cleanup

## Folder Structure

- `01_basics/`: intro notes, variables, printing, operators, and data types
- `02_input_and_conditionals/`: input, type conversion, `if`, `elif`, `else`
- `03_loops/`: `while`, `for`, `break`, `continue`, games, nested loops
- `04_functions/`: functions, arguments, return values, Collatz practice
- `05_modules_and_packages/`: imports, standard library, virtual environments, Flask
- `06_error_handling/`: `try`, `except`, and common runtime errors
- `07_lists/`: list indexes, CRUD, slicing, and user-input lists

Each Python lesson has a matching `.md` notes file in the same folder.
