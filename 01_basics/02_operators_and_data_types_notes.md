## What It Is

Data types tell Python what kind of value something is. Operators are symbols
that perform actions like math or comparison.

## What It Does

- `str` stores text.
- `int` stores whole numbers.
- `float` stores decimal numbers.
- `bool` stores `True` or `False`.
- Arithmetic operators do math.
- Comparison operators return `True` or `False`.

## Why Use It

Programs need to treat values differently. Text can be joined, numbers can be
calculated, and booleans can decide which code should run.

## Example

```python
name = 'john'
age = 24
height = 5.7

print(age + 1)
print(height > 5)
print(name == 'john')
```

## Watch Out For

- `'10'` is a string, but `10` is an integer.
- `/` returns a float, even when the answer looks like a whole number.
- `=` assigns a value, but `==` compares two values.
- Spelling matters: `True` and `False` must start with capital letters.
