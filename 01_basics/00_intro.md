# Python Programming Language

## What Is a Language?

A language helps people communicate with each other.

Examples:

- Telugu
- English
- German

Words and sentences have rules. Programming languages also have rules.

## What Is a Programming Language?

A programming language helps people communicate with computers.

Examples:

- C
- C++
- Java
- Python

When we run Python code, the Python interpreter reads our code and tells the
computer what to do.

## Why Python?

Python is a good first programming language because it has simple syntax and is
used in many areas:

- Web development
- Machine learning
- Data science
- Automation
- DevOps
- Problem solving

## Data Types

Data means information. Python stores different kinds of information using data
types.

Common data types:

- `str`: text, such as `'hello'` or `"good morning"`
- `int`: whole numbers, such as `10` or `100`
- `float`: decimal numbers, such as `3.14` or `10.5`
- `bool`: truth values, either `True` or `False`

## Strings

Strings are words or sentences inside quotes.

```python
'mouse'
"This is my pen"
```

Joining strings is called concatenation.

```python
'hi ' + 'there'
```

Output:

```text
hi there
```

## Arithmetic Operators

```python
1 + 1      # addition
5 - 2      # subtraction
2 * 3      # multiplication
4 / 2      # division, gives 2.0
4 // 2     # integer division, gives 2
2 ** 3     # exponent, gives 8
```

## Variables

Variables are labels for values.

```python
name = 'mouse'
age = 25
height = 5.6
```

Use clear variable names:

```python
computer_name = 'Apple'
pet_age = 5
```

## Built-In Functions

Python gives us ready-made functions:

- `print()`: show output
- `input()`: receive keyboard input
- `str()`: convert to string
- `int()`: convert to integer
- `float()`: convert to decimal number

## Comparison Operators

Comparison operators return `True` or `False`.

```python
2 > 1       # True
10 < 5      # False
'hi' == 'hi'
'Hi' != 'hi'
```

Common comparison operators:

- `>` greater than
- `>=` greater than or equal to
- `<` less than
- `<=` less than or equal to
- `==` equal to
- `!=` not equal to

## Boolean Operators

Boolean operators combine conditions:

- `and`: all conditions must be true
- `or`: at least one condition must be true
- `not`: reverses the value

```python
2 > 1 and 10 < 5
10 > 1 or 10 < 5
not True
```
